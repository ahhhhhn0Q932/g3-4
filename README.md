# 高三(4)班 · 班级管理系统

一个面向班级日常管理的一体化网页应用：作业、请假、提醒、班级日志、工具箱、激励语句和云端同步都集中在一个页面里。项目采用单文件 HTML + CSS + JavaScript 实现，打开即用，数据默认保存在浏览器本地，也可接入 Supabase 实现多设备同步。

- 在线访问：<https://ahhhhhn0Q932.github.io/g3-4/>
- 代码仓库：<https://github.com/ahhhhhn0Q932/g3-4>
- 云端配置说明：[CLOUD_SETUP.md](CLOUD_SETUP.md)

## 功能说明

### 仪表盘

- 展示随机激励语句，可切换、收藏，并显示标签和署名。
- 生日栏展示当天及未来 60 天的学生与教师生日，教师会标注“教师”。
- 高考倒计时根据设置中的高考日期自动计算，支持“今天”“已结束”“未设置”等状态。
- 高考倒计时与每日提醒之间展示北京时间（GMT+8，精确到秒）和网站运行时长。
- 每日提醒展示当天未完成和已完成的提醒，可直接进入提醒页管理。
- 目录卡片快速进入今日总览、请假登记、每日提醒等页面。
- 页面底部展示本地保存、云端同步的最近时间及云端状态。

### 今日总览

- 按语文、数学、英语、物理、化学、地理、其他七个科目分组展示作业。
- 建议时长与截止日期显示在每条作业行的末尾；过期截止日期会标红。
- 每个科目队尾有“＋”按钮，展开紧凑面板添加作业。
- 截止日期不勾选时默认当天；勾选后作业会一直显示到截止日。
- 右侧月历支持切换月份、回到今天，有记录的日期会显示圆点。
- 点击月历日期，总览切换为“历史回看”，以只读方式展示当天作业、请假和提醒，不会弹出新窗口。
- 历史模式下作业不可编辑，请假和提醒也仅作展示。
- 页头“显示模式”按钮可隐藏导航、页头和其他操作，只保留作业、月历、请假与每日提醒，作业字号自动放大，适合课堂投屏；右上角按钮可退出。
- 请假卡片的“应到/实到”数字可点击：应到名单决定当天统计范围，实到名单只能从应到学生中核对；请假由两者自动得出。

### 作业管理

- 作业包含科目、内容、建议时长和截止日期。
- 支持行内编辑、删除和回车快速添加。
- 截止日期早于今天时，截止标签会变为醒目的过期状态。
- 历史回看按作业的布置日期筛选，不影响当天的截止显示逻辑。

### 请假登记

- 节次共 14 项：早读、第一节课、第二节课、大课间、第三节课、第四节课、午练、午休、第五节课、第六节课、第七节课、第八九节课、第一节晚自习、第二节晚自习。
- 请假学生从当天“应到名单”中勾选，支持按姓名筛选、多选、全选、反选和清空；不在应到名单内的学生不参与统计。
- 支持点击多选节次、按住 Shift 连续选择、全选和清空。
- 展示时自动把连续节次压缩为“头~尾”区间，例如“早读~第二节课（共 3 节）”。
- 支持按日期查看出勤统计和历史请假记录，可切换“请假中/已销假”；当天请假超过 10 人时自动折叠。
- 同一日期、同一姓名且节次有重叠时，会阻止重复登记。

### 每日提醒

- 可发布提醒并设置截止日期；不勾选则默认当天截止。
- 提醒从发布日起持续显示到截止日，截止前在总览和仪表盘保持可见。
- 当前提醒和历史提醒分区展示，支持勾选完成和删除。
- 仪表盘展示截止前的提醒，并优先显示未完成项。

### 班级日志

- 左侧月历支持切换月份、回到今天，有记录的日期会显示圆点。
- 点击日期即可查看当天的作业、请假、提醒、生日和留言存档。
- 双击“班级日志”导航或页头，可查看班级人数、生日填写情况、班主任和教师团队。
- 支持快捷发送留言、按日期查看和导出日志。
- 访客也可以正常留言。

### 工具箱

- **幸运星**：可切换抽取学生、老师或全体；名单分别来自学生档案和教师档案，老师名字带“老师”后缀，带滚动动画并避免连续抽到同一人。
- **随机数**：可设置最小值和最大值，范围写反会自动纠正，支持回车抽取。
- **回声洞**：维护仪表盘的激励语句，可添加、删除，选择标签并填写可选署名；署名会随语句一起展示。访客只读。
- **Issue 提交**：所有人可提交和删除待办式问题报告，显示提交身份、时间、状态与回复；仅管理员可以回复并勾选解决。

### 设置

- 修改班级名称、班级简称、高考日期；班级人数自动取学生档案总数，不再手动填写。
- 学生档案已内置 2024 级 4 班 55 人名单，可添加、修改、删除学生；生日为可选项，名单按姓名字母排序，列表固定高度、超出后滚动查看。添加和修改使用弹出窗口。
- 教师档案记录姓名、任教学科、角色、生日和祝福；已内置 6 位任课教师，可添加、修改、删除，班主任用于班级信息展示。添加和修改使用弹出窗口。
- 修改管理员密码；默认密码为 `123`，部署后建议立即修改。
- “身份与访客权限”集中处理切换身份和访客权限：管理员可勾选访客能使用的功能（含独立的“学生档案”修改权限），保存后立即生效。
- “同步设置”集中数据备份与云同步：导出、导入、载入示例、清空数据，以及手动上传/拉取。
- “维护”展示版本更新日志和 GitHub 仓库入口；双击维护图标可查看项目 Token 用量与估算消耗。
- 访客进入设置页时默认只读，不能保存、导入、清空或修改密码；导出数据仍可使用。管理员可单独开放“学生档案”权限，开放后访客可添加、修改、删除学生。

### 登录与权限

- 进入系统时选择“访客进入”或“管理员进入”。
- 管理员拥有全部修改权限。
- 访客不能修改作业、回声洞、设置和每日提醒，但可以查看总览和月历、登记/销假、写班级日志、使用幸运星和随机数、切换激励语句、导出数据；管理员开放“学生档案”权限后还可以维护学生名单。
- 管理员进入需要密码；默认密码为 `123`，可在“设置 → 管理员密码”中修改。
- 页脚显示当前身份；切换身份入口位于“设置 → 身份与访客权限”，刷新页面后会重新选择身份。

### 云端同步

- 数据默认保存在浏览器 `localStorage`，断网时页面仍可正常使用。
- 接入 Supabase 后，保存会自动触发同步，登录和打开页面时会拉取云端数据，并定时检查远端更新。
- 管理员同步完整数据；访客只合并请假、班级日志留言和 Issue 看板，不会覆盖作业、设置等内容。
- 设置页提供“手动云同步”，用于换设备或网络恢复后立即刷新。
- 仪表盘底部显示最近一次本地保存和云端同步时间，云端异常时会给出提示。
- 云端表结构和 RPC 见 [supabase-schema.sql](supabase-schema.sql)，首次使用需按 [CLOUD_SETUP.md](CLOUD_SETUP.md) 在 Supabase SQL Editor 中执行一次建表脚本。

## 技术说明

- **前端**：原生 HTML、CSS、JavaScript，单文件 `index.html`，无需构建工具。
- **本地存储**：`localStorage` 缓存完整班级数据，并单独保存同步时间等设备级元信息。
- **云端**：Supabase PostgreSQL + Row Level Security + SECURITY DEFINER RPC。
  - `class_state`：保存班级数据 JSON 和版本号。
  - `class_secret`：保存管理员密码的 bcrypt 哈希。
  - `check_admin`、`save_state`、`change_admin_pwd`：负责登录校验、同步写入和改密。
