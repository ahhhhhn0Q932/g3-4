**已完成的功能概览**

**界面与总览**
- 页面整体加宽，最大宽度 1680px，减少两侧留白。
- 今日总览右侧新增月历，点击日期直接在原页面切换到“历史回看”，只读查看当天作业、请假和提醒，可一键回到今天。
- 今日总览左上角 📋 Logo 双击打开腾讯文档链接。

**作业**
- 每个科目的作业栏改为队尾“＋”小按钮，点击展开紧凑添加面板。
- 添加作业时可填建议时长、勾选截止日期；不勾选则默认当天。
- 有截止日期的作业会一直显示到截止日；历史回看仍按布置日期查看。
- 作业卡片展示“建议 N 分钟”和截止日期，过期截止日期标红。

**首页**
- 生日栏与目录栏之间新增左右两块：高考倒计时、今日每日提醒。
- 倒计时支持今天、已结束、未设置等状态。

**工具箱与彩蛋**
- 随机抽学生：名单来自生日档案，带滚动动画且避免连续重复。
- 随机数：可设置最小/最大值，支持回车抽取。
- 回声洞：可添加/删除激励语句，选择 tag、可选署名；首页展示时签名随语句显示，访客只读。
- 彩蛋自己找

**请假**
- 节次改为 14 项：早读、第一至第四节课、大课间、午练、午休、第五至第七节课、第八九节课、两节晚自习。
- 支持多选、按住 Shift 连续选择、全选和清空。
- 展示时把连续节次压缩为“头~尾”区间，例如“早读~第二节课”。

**登录与权限**
- 进入时选择访客或管理员；管理员默认密码 `123`，可在设置中修改。
- 访客不能修改作业、回声洞、设置和每日提醒，其余功能可正常使用。
- 页脚支持“切换身份”，刷新后重新选择身份。
- 登录页的班级名称、数字 Logo 与设置保持同步。
